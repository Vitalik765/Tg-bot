Fitness_GPT_Bot - бот для фитнеса
Это Telegram-бот, написанный на Python, который использует API OpenAI для составления плана тренировок и питания на основе введенных пользователем данных с помощью модели "text-davinci-003". В диалоге с ботом используется пошаговый подход, а на некоторых подсказках есть кнопки.

Что нужно для запуска:
Установите библиотеки telebot и openai.
Создайте собственного Telegram-бота, отправив сообщение «BotFather» в Telegram.
Замените токены Telegram и OpenAI API на свои. (Вам понадобится платная учетная запись OpenAI)
